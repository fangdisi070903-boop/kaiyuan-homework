## 二、报名流程（需本人账号操作）

1. 使用微信扫描课程群/海报中的“扫码报名”二维码，进入报名页；
2. 使用本人手机号注册或登录华为账号；
3. 按提示完成实名认证（可能需要身份证信息与人脸核验）；
4. 选择赛道与学校信息（上海杉达学院），提交报名；
5. 扫描“官方交流群”二维码加入赛事群，接收赛题与直播通知；
6. 报名成功后截图保存“报名成功”页面，命名为 `01-报名成功.png`。

## 三、免费卡时领取流程（需本人账号操作）

1. 登录昇腾社区（<https://www.hiascend.com/>）或赛事指定的云端环境入口；
2. 进入“开发者 / 算力”或“免费算力”专区，完成开发者认证；
3. 找到本次赛事对应的免费卡时/代金券领取入口；
4. 领取后记录额度、有效期与适用区域；
5. 在云端 Notebook 或 ModelArts 中创建实例，确认可看到 NPU 设备（`npu-smi info`）；
6. 截图保存卡时余额与实例页面，分别命名为 `02-卡时额度.png`、`03-NPU实例.png`。
