## 2. 对外报价验算（课程公式）

> 对外报价 =（人力 + 模型 + 算力 + 实施）×（1 + 风险预留率）×（1 + 目标加成率）
> 风险预留取 **10%**（范围清晰、有验收阈值）；目标加成取 **25%**（对应毛利率 20%，不是 25%）。

| 部分 | 内部成本 | ×1.10 ×1.25 | 对外定价 |
| --- | ---: | ---: | ---: |
| 一次性实施（人力 + 数据一次性） | 60,078.37 | 82,607.76 | **80,000**（取整，与已批预算一致） |
| 年度服务（模型 + 服务器 + 短信 + 运维） | 25,690.27 | 35,324.12 | **36,000 / 年** |
| 满 12 个月口径合计 | 85,768.64 | 117,931.88 | 118,607.76 |
| **首年实际报价**（服务按 9 个月计） | — | — | **107,000**（80,000 + 27,000） |

- 首年报价毛利 = 107,000 − 85,768.64 = **21,231.36 元（19.84%）**。
- 满年报价与首年报价差 11,607.76 元 = 实施取整让利 2,607.76 + 首年 3 个月服务费让利 9,000。
- 报价与项目文档一致：01 §4.2 已批预算 8 万元；05 §4.1 首年 10.7 万元（8 万 + 2.7 万）。

## 3. 报价模式：组合报价

**选择：一次性实施费 + 年服务费 + 超量单价。**

一句话理由：试点范围清晰、但真实用量与效果尚未验证，实施费覆盖交付风险，年服务费覆盖运维与模型成本，超量单价覆盖用量上涨风险——三块成本各自对应一笔收入。

不选其他三种的原因：

| 模式 | 为什么不选 |
| --- | --- |
| 人天制 | 客户是医院，预算制、需要封顶价；按人天结算无法过立项审批 |
| 项目总价制 | 效果（漏访率、再入院率）依赖真实试点，范围无法一次性锁死 |
| 订阅制 | 只有 1 个客户、尚未产品化，没有多租户复用的成本摊薄 |
| 按效果付费 | 再入院率受病种、季节、依从性影响，归因无法在 3 个月内验证 |
