## 运行方式

方式一：直接双击 `index.html`，用浏览器打开。

方式二：使用静态服务器（推荐，行为与线上一致）：

```bash
cd 第一周-个人简历网站
python3 -m http.server 8000
```

浏览器访问 <http://localhost:8000>。

## 实现说明

1. 无任何外部依赖、无 CDN、无第三方字体，断网也能完整显示。
2. 使用 CSS 自定义属性实现明暗主题；默认跟随系统 `prefers-color-scheme`，用户手动切换后写入 `localStorage`。
3. 内容渐入使用纯 CSS 动画，页面加载后即显示，避免依赖 JavaScript 或滚动观察导致内容不可见；导航高亮使用 `IntersectionObserver`，在不支持时自动降级。
4. 使用语义化标签与 `aria-*` 属性，提供键盘焦点样式和“跳到主要内容”链接。
5. 提供 `@media print` 样式，可直接打印为 PDF 简历。
