## 本地运行

### 第一周：个人简历网站

直接双击打开 `第一周-个人简历网站/index.html`，或在目录内启动静态服务器：

```bash
cd 第一周-个人简历网站
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

### 第二周：CANN 初步代码

CPU 侧金标准测试（无需 NPU）：

```bash
cd 第二周-CANN初步代码/python
python3 -m unittest -v test_golden_add.py
```

Ascend C 算子需在安装 CANN 工具链的昇腾环境中编译，步骤见 [第二周 README](第二周-CANN初步代码/README.md)。

### 第四周：许可证合规扫描

复现命令与工具版本见 [第四周 README](第四周-开源许可证合规分析/README.md) 与 `scan/environment.txt`。
